# 🎮 Dot's Command 2.0 Beta

Modern ve kullanışlı bir Minecraft Java 26.1.2 komut GUI modu.

## ✨ Özellikler

- 🎮 Right Shift ile GUI açma
- 🔎 Komut arama
- 📂 Kategorilere ayrılmış komutlar
- ⭐ Favori komutlar
- 🕘 Son kullanılan komutlar
- 🌍 7 farklı dil desteği
- 🖥️ F11 / Fullscreen uyumluluğu
- 🎵 GUI sesleri ve animasyonlar
- ⌨️ Dot komutlarında TAB kapalı
- 🏠 Tek oyunculu dünya desteği

## 📦 Gereksinimler

- Minecraft Java Edition **26.1.2**
- **Fabric Loader**
- **Fabric API**

## 📥 Kurulum

1. Minecraft 26.1.2 için Fabric Loader kurun.
2. Fabric API'yi `mods` klasörüne koyun.
3. `dotcommands-2.0.0-beta.jar` dosyasını `.minecraft/mods` klasörüne koyun.
4. Minecraft'ı Fabric profiliyle başlatın.
5. Dünyaya girdikten sonra **Right Shift** tuşuna basın.

## ⚠️ Önemli

Bu Beta sürümü öncelikle **tek oyunculu dünyalar** için tasarlanmıştır.

Gerçek Vanilla/Aternos sunucularında mod, sunucunun OP/yetki sistemini bypass etmez.

Sunucu tarafı desteği gelecekte geliştirilecektir.
